GET STARTED

Models & setup.

Install PyTorch for your GPU, then install this package. Downloads include the complete checkpoint and tokenizer files.

python -m pip install -e ".[dev]"

1.7B Base + 1.7B VoiceDesign are the recommended pair. 0.6B Base is the smaller cloning alternative. Downloads can be several GB; interrupted Hub downloads can be resumed.

Already downloaded? Paste the local checkpoint folder into the Design or Dialogue form.
